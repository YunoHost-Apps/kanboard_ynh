### Sélectionnez votre mode d'authentification préféré pour cette app
Ce paquet configure l'authentification `SSO` par défaut, grâce à laquelle un utilisateur Yunohost authentifié peut accéder à cette application directement sans étape d'authentification supplémentaire.
Si vous préférez utiliser le système d'authentification intégré à cette application de façon à qu'elle puisse être utilisée par des personnes n'ayant pas de compte YunoHost sur ce serveur, vous pouvez basculer vers le mode d'authentification intégré ("built-in") via le panneau de configuration de cette application.
Notez qu'il faut choisir entre l'un OU l'autre: mélanger les utilisateurs créés via cette application et via YunoHost n'est pas une fonctionnalité prise en charge.

En sélectionnant le mode d'authentifcation "App" pour la première fois, vous devez vous connecter à l'application en utilisant le compte `admin` créé par défaut dans la base de données de l'application. Le mot de passe de ce compte est `admin` - assurez-vous de le changer immédiatemment!
